# SnapPDF

Convert. Merge. Split. Compress.

SnapPDF is a simple tool to work with images and PDF files. It runs in your browser and also works offline. You can use it on a phone or a computer. You can also install it as an app.

Live site: https://madebyzen.github.io/SnapPDF/

## What it does

You can turn images into a PDF and set the order of the pages. You can turn PDF pages back into images. You can merge many PDFs into one file and split a PDF into smaller parts. You can also compress and resize images and PDFs to make the files smaller.

## Settings

You can choose the page size, or keep the same size as the image. You can make one PDF for each image if you want. You can set your own file name using {name}, {n}, {w} and {h}. You can also name the ZIP folder. A Theme button lets you change how the app looks.

## How to use

Open the site. Pick a tool from the tabs at the top, such as Images to PDF, PDF to Images or Merge PDF. Drop your files in the box, or choose them from your device. Change the settings if you need to. Then create the file and download it.

## Install as an app

Open the site in Chrome. Tap the install option in the menu. The app will then open like a normal mobile app. It also works without internet after the first visit.

## Files in this project

index.html holds the page. style.css holds the design. script.js holds the main code. sw.js is the service worker that makes offline use possible. manifest.json holds the app name and icons.
